New Functionality
^^^^^^^^^^^^^^^^^

- The default user endpoint configuration template generated by
  ``globus-compute-endpoint configure`` now builds a dynamic `uv`__ environment
  on every submission. This environment matches the Python and Globus Compute
  SDK versions of the submitting user's local runtime, if that information is
  available, and is reused between invocations whenever possible.

  Additionally, the default template now honors a ``requirements`` option, which
  takes a multi-line ``requirements.txt``-style string. When specified, the
  packages in this list are installed to the user's environment.

  For more information, see `Task-time Python Environments
  <https://globus-compute.readthedocs.io/en/stable/endpoints/templates.html#task-time-python-environments>`_.

.. __: https://docs.astral.sh/uv/
